QEMU matrix control
===================

Unshipped automation helper. Defaults idle. Explicit emulator-only mailbox
commands invoke normal ML menu APIs from a DryOS task. No model addresses or
sensor access. Optional synthetic frames use only owned temporary buffers and
call the actual loaded Mirror module. Their results never attest Canon image
delivery. The synthetic test may borrow a temporary photo-memory allocation,
then frees it before OFF/cleanup; production Mirror's preview never uses this
fallback. Native capture is cancelled before fixture delivery. A negative case
corrupts one owned output byte to verify the independent checker. Never install
this helper on a camera or use it during actual shooting.

Registered RAW fixture
----------------------

Dev7 also calls the loaded module's registered Canon14 primitive through the
real cross-module loader. Two synthetic patterns cover 44 RAW edge layouts
each, with an independent pixel oracle, boundary/guard checks and deliberate
output corruption. These 88 tiny-frame tests establish neither Canon RAW
ownership nor capture timing, and never invoke a Canon shutter or buffer.
