# Mirror Worlds 0.2.0 — first public release

Creative mirror photography for the **original Canon EOS M**, by **Max Seelig (MAXmade)**.

See the reflections in LiveView and use the normal shutter button to save an already mirrored **Canon CR2 RAW photo**. Canon handles immediate review and playback.

## Included

- Seven placements: Left, Right, Top, Bottom, Left + Right, Top + Bottom and All edges.
- Independent border Width and Height: Half through Sixth. Opposing edges start at Third to preserve an original center.
- Mirrored corners when All edges is selected.
- Automatic rearming between single photos.
- Remembered ON/OFF, placement and sizes after restart.
- Canon autofocus and Auto ISO, without menu photo saving or diagnostic arming.

## Compatibility

**Developed and tested on the original Canon EOS M, Canon firmware 2.0.2, Magic Lantern dev build 2025-06-20 / EOSM.202.** Other cameras, EOS M models and ML builds are not validated.

Use A+ / Auto ISO / Canon RAW / single-shot drive, native 1× LiveView and Global Draw ON. Magic Lantern must already be installed.

## Install

With the camera OFF, copy `ML/MODULES/mirror.mo` from the ZIP to the same folder on your card. Enable mirror.mo in ML’s Modules tab and restart. Open Shoot → Mirror Worlds, turn Live effect ON, choose the edges and sizes, close the menu and shoot.

## Download files

- **MIRROR-0.2.0-EOSM202.zip** — recommended; module, exact source, license and build information.
- **mirror.mo** — the same module, for people who only need that file.
- **SHA256SUMS** — checksums for both downloads.

This publication preserves the existing 0.2.0 module unchanged. Single-shot photos are supported; continuous drive, video, remote triggers and long exposures are outside this release’s workflow.
